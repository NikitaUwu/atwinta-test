# Работа с АГРО

- Пишите по-русски. Прочитайте README.md перед работой.
- Меняйте исходники src/, затем запускайте python scripts/build.py.
- Проверяйте затронутые сценарии и адаптивность карточек; сохраняйте доступность клавиатуры.
- Данные демонстрационные и хранятся локально. Технологические решения принимает специалист заказчика.
- Не добавляйте секреты, настройки авторизации, посторонние проекты и исследовательские материалы.
- Публикация требует поручения пользователя и собственного разрешённого доступа к Vercel.
